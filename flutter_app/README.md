# flutter_app

## Dice Roller Practice

This is a starter version of the dice roller. The app currently shows dice face
1; the button is intentionally not connected yet.

Try completing it in these steps:

1. Change `GradientContainer` into a stateful widget.
2. Add a state value that starts at `1`.
3. Create a method that picks a random number from `1` to `6`.
4. Update the state when the button is pressed.
5. Use the state value in the dice image path so the image changes after each
   roll.

The six dice images are in `assets/images/`, and `pubspec.yaml` already lists
them as assets.

## Run in a browser

From this project folder, run one of these commands:

```powershell
flutter run -d chrome
flutter run -d edge
```

If Flutter does not list either browser, check that Chrome or Edge is installed
and run `flutter devices` to confirm that Flutter can detect it.
